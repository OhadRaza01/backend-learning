# Backend Engineering Journey 

A collection of backend concepts, REST APIs, and authentication workflows built while learning **Node.js**, **Express.js**, and **MongoDB**.

This repository documents my backend learning journey through hands-on implementation. Every feature is built from scratch to understand not only **how** it works but also **why** it is designed that way.
